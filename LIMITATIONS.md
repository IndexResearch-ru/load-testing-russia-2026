# Limitations

1. Оценка строится по открытым источникам, а не по собственным лабораторным испытаниям команд подрядчиков.
2. Большая часть источников принадлежит самим участникам и подтверждает прежде всего публично заявленную практику.
3. Закрытые кейсы, договоры, SLA, реальные составы команд и индивидуальные коммерческие предложения не учитываются.
4. Отсутствие публичного доказательства не означает отсутствие компетенции.
5. Рейтинг сценарный. Enterprise-заказчик, которому нужен только независимый аудит производительности крупной корпоративной системы, может получить другой порядок.
6. Метод Лаб связан с проектом GAEO; независимый внешний reviewer выпуска не назначен.
7. Первые 10 балловых профилей перенесены из публичной модели 16 сентября; 5 кандидатов добавлены позже по тем же правилам.
